# Retail Sales Management System

## Overview
A full-stack Retail Sales Management System built with React (Vite) and Node.js (Express).
Key features include Search, Filtering, Sorting, and Pagination.

## Tech Stack
- **Frontend**: React, Vite, TailwindCSS
- **Backend**: Node.js, Express, In-Memory Data Service

## Setup
1. `npm install` (root) - Check `package.json` for helper scripts.
2. `npm run install:all` to install dependencies in root, backend, and frontend.
3. `npm run dev` to start both backend and frontend.

More details in `docs/architecture.md`.
